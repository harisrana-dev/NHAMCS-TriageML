# NHAMCS-TriageML — core requirements (single authoritative manifest)
#
# Scope: data loading + integrity verification + leakage-free preprocessing
# pipeline + EDA + Part 2/3 evaluation framework + the test suite.
# Deliberately minimal. Optional model libraries are NOT installed here; they
# have their own manifests (Issue #23):
#   requirements-xgboost.txt    XGBoost (Issue #13)
#   requirements-torch-cpu.txt  PyTorch, CPU-only wheels (Issue #16)
#
# Supported Python: CPython 3.13.x. The reference/tested environment for every
# result in this repository is Windows 11, CPython 3.13.5 x64 (docs/environment.md).
# 3.13.5 is the tested reference patch release, not the only accepted one.
#
# Bounds follow one rule: lower bound = the version observed in the reference
# environment; upper bound = the next major release, so a major-version bump
# fails loudly instead of silently changing behaviour.
#
# Reference environment (CPython 3.13.5, Windows 11 x64) — installed and verified:
#   pandas 2.3.3 · numpy 2.5.4 · scikit-learn 1.9.1 · scipy 1.18.1
#   matplotlib 3.11.2 · jupyterlab 4.6.4 · ipykernel 7.4.0 · nbformat 5.11.1
#   nbclient 0.11.0 · pytest 9.1.1
#
# The Part 1 notebook was originally executed under pandas 2.3.0, numpy 2.2.6,
# scikit-learn 1.7.0, scipy 1.15.3; its committed outputs now come from a
# re-run under the reference environment above (Python 3.13.5, sklearn 1.9.1).
#
# NOTE: matplotlib 3.11 is required, not optional. The four EDA figures are part
# of the Part 1 deliverable, and the notebook asserts on the transformed array,
# so a run without it fails loudly rather than producing a notebook with no plots.
#
# Part 2 note (Issue #3, PR #8): scikit-learn is pinned to exactly 1.9.1.
# StratifiedGroupKFold fold assignments can differ between scikit-learn versions
# even with shuffle=True and random_state=42 unchanged, so the Part 2 fold-level
# results in docs/decision_tree_results.md were produced under 1.9.1 and should
# be read against this pin. This pin also governs the Part 3 nested-tuning folds
# (docs/nested_tuning_protocol.md).
#
# Interpretability (Issue #23 decision): scikit-learn-native tools only
# (sklearn.inspection.permutation_importance and friends). SHAP and LIME are
# deliberately NOT dependencies yet.
